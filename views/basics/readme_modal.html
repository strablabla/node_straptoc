Aide

Navigation

Aller en mode texte Double-clic
Retour au mode HTML (sauvegarde) Clic droit
Fermer les modales Echap
Rechercher dans toutes les pages Ctrl+Shift+F

Edition (mode texte)

Sauvegarder et retour HTML Alt + S

Listes pliables

Plier/déplier toutes les listes Alt + L

Panneaux

Ouvrir/fermer la playlist Clic casque
Ouvrir/fermer l'agenda Clic calendrier
Ouvrir/fermer l'aide Clic ?

Vidéos YouTube

[titre ;;](https://youtube.com/...)
Insère une vidéo YouTube via iframe

Vidéos locales

[titre %%](video.mp4)
Insère une vidéo locale (mp4, webm, ogg...)

PDFs

[titre §§](document.pdf)
Insère un PDF avec balise object

iFrames

[titre ,,](page.html)
Insère n'importe quelle iframe

Images avec légende

[légende %caption%](image.jpg)
Insère une image avec une légende en dessous

Listes spéciales

* $vid
[Titre %%](video.mp4)
[Titre2 %%](video2.mp4)
Liste de vidéos locales avec lazy loading
* $pdf
[Doc1 §§](doc1.pdf)
[Doc2 §§](doc2.pdf)
Liste de PDFs
* $htm
[Page1 ,,](page1.html)
[Page2 ,,](page2.html)
Liste d'iframes HTML
* $portf 3
![](img1.jpg)
![](img2.jpg)
Portfolio d'images (3 colonnes par défaut)
* $carr nom
![](img1.jpg)
![](img2.jpg)
Carrousel d'images

Chemin commun

* $vid
+++ dossier/videos/
[Vid1 %%](v1.mp4)
[Vid2 %%](v2.mp4)
+++ définit un chemin racine pour tous les fichiers suivants

Dates

.date 25_1_24
Crée un marqueur de date (format jour_mois_année)

Texte barré

texte %%%
Le texte avant %%% est affiché barré

Tooltips

# Titre {info-bulle ici}
Ajoute une info-bulle après un titre h1 ou h2

Listes pliables

* élément ::
  * sous-élément
:: crée une liste pliable (fermée par défaut). Alt+L pour plier/déplier

Paramètres de page

§width_video 80%
§width_pdf 80%
§height_pdf 500
§width_iframe 900
§height_iframe 400
§width_content 800
Configure les dimensions des éléments (en début de document)

Désactivation

§notoc
§novideo
§noiframe
Désactive la table des matières, les vidéos ou les iframes

Couleurs et copie

@rouge texte
Change la couleur du texte (dans les listes)
@@texte@@
Copier/coller un élément de liste

Blocs de code

\`\`\`
code non interprété
\`\`\`
Le contenu n'est pas interprété. Échappez [ avec \[ pour éviter les liens

Alertes agenda

!alert votre message
Dans une note d'agenda, crée une alerte (point bleu)
